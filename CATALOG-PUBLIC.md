# Публичный каталог без входа

На GitHub Pages работают таблица, поиск, фильтры, сортировка, страницы и экспорт выбранных строк в CSV. Записи публикует владелец через репозиторий. Вход для просмотра не нужен; открытых форм записи в общую базу нет. Существующий серверный код авторизации сохранён для следующего этапа.

Данные: `public/data/channels.json`. Публичный набор содержит только ссылку MAX, название, описание, участников, тип, аватарку, публичные источники и время проверки. Пользовательские заметки, технические ошибки чекера и произвольные столбцы таблиц не публикуются. Одинаковые ссылки объединяются, регистр приглашений `/join/…` сохраняется.

Импорт выгрузок владельцем:

```sh
python3 scripts/import-public-catalog.py --links links.json --checked checked.json --avatars avatars.json
npm test
npm run build
```

`links.json` и `checked.json` содержат массив `rows`, `avatars.json` — соответствие URL MAX → публичный HTTPS-URL изображения. Отсутствующие сведения показываются как отсутствующие; они не заменяются выдуманными описаниями или нулём участников.

Единый клиентский движок таблицы: `public/catalog-widget.mjs` и `public/catalog-model.mjs`. Он используется компонентом Next.js и статической версией. Публикация Pages поверх существующего дерева:

```sh
python3 scripts/build-public-pages.py --site-dir /path/to/staging-site
```

Обычный `scripts/export-pages.py` автоматически применяет эту накладку. Для отдельной сборки задайте `PAGES_OUTPUT_DIR` и `PAGES_PORT`, чтобы сохранить предыдущую выгрузку. Скрипт сохраняет существующие изображения, анимацию и остальные разделы; главная, каталог и рейтинг получают работающую публичную базу.

Палитра и шрифт сохранены: жёлтая бумага #f4d35e, карточки #fff8e4, чернила #1b1714, акцент #2c6bed, Source Sans 3. Таблица ориентирована на сравнение строк; на узком экране прокручивается внутри контейнера. Аватарки загружаются лениво с публичного сервера; при ошибке показываются инициалы.
